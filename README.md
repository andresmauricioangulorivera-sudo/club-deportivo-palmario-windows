# Club Deportivo Palmario para Windows

Aplicación de escritorio que abre el sitio del club en una ventana de PC. Necesita conexión a internet.

## Descargar e instalar

1. Abre la pestaña **Releases** de este repositorio.
2. En la versión **Club Deportivo Palmario para Windows**, descarga el archivo que termina en `Setup.exe`.
3. Abre el archivo descargado y sigue los pasos del instalador.

Enlace directo a la descarga más reciente: https://github.com/andresmauricioangulorivera-sudo/club-deportivo-palmario-windows/releases/latest
